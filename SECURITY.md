# Security policy

Please do not file public issues for vulnerabilities that could expose credentials, execute untrusted code, cause uncontrolled resource consumption, or disclose private machine details. Contact the repository maintainer privately through the GitHub security advisory flow.

XLAxiom accepts declarative JSON only and does not use pickle or execute workload-supplied code. Nevertheless, numerical workloads can consume substantial resources; run untrusted cases only with suitable process and resource isolation.
